Synthetic · sample data

Designed to explore the workflow

All 24 runs, test outcomes, scores, response times, and model configurations are representative fixtures created for this gallery. They are not measurements or verified provider specifications and should not guide a production model choice.

Real inference · no data

A separate place for real evidence

Add provider metadata and models, sync an accessible catalog, or import measured reports. Real reports are user-declared live inference, not independently verified execution. Synthetic fixtures are never relabeled or combined with real results. No inference is run by this gallery.

How sample scores work

Score = passed test cases ÷ total test cases × 100. The all-suites score is weighted by case count. Scores use the latest report per model and suite. Latency is the median of those runs’ median request latencies. Response rate counts completed responses, including failed assertions, and excludes timeouts and errors. Real comparisons require matching suite versions, case assertions, and recorded request settings.
